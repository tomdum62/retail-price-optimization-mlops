1. Flux Pipeline Complet

Le pipeline s'execute en mode bi-hebdomadaire (vendredi = run principal J+7, mardi = reajustement J+4). Chaque run traverse 5 etapes sequentielles, avec une boucle iterative a l'etape 4.

1
FORECAST — LightGBM V2
Predictions Qte_Pred et CA_Pred par produit × base × jour sur l'horizon (J+7 vendredi, J+4 mardi). Modele LightGBM, 53 features, 1.3% MAPE au CA base.
↓
2
SEPARATION — 3 populations
SUIVI Assortiment de base → optimise
NON SUIVI Operations promo → passthrough (JAMAIS touche)
POLCO Prix imposes (ITM only) → reporte a part
↓
3
PEREQUATION — Cible MLNI NS
SE CALCULE AVANT LE MONTE CARLO. Equilibre la marge entre SUIVI et NON SUIVI. Calcule le MLNI_NS_Requis pour atteindre l'objectif global. Ce taux devient une cible au meme titre que l'indice concurrent.
↓
4
MONTE CARLO ITERATIF — par enseigne × base
Boucle iterative (max 5 iterations) : generer 10K scenarios → scorer → check portfolio → si non convergent → re-iterer avec bornes ajustees.
↓
5
SORTIE — Tables Databricks Delta
6 tables en mode append, partitionnees par run_id. Archivage des recommandations pour historique et audit. Compatible Power BI / DAX.

3. Calculs & Formules Financieres

CRITIQUES — Ne pas modifier sans validation metier + recette complete. Les denominateurs des taux de marge sont specifiques au modele SCAFLF.

3.1 Les 3 marges du modele SCAFLF

Valeurs

CA_TTC = PVC # prix TTC consommateur CA_HT = PVC / (1 + TVA/100) # TVA F&L = 5.5% MADH_Val = CA_HT - PC # marge adherent MFIL_Val = PC - PA # marge filiere MLNI_Val = CA_HT - PA # marge ligne nette ITM

Taux (%)

MADH_Taux = MADH_Val / CA_TTC × 100 # denom = CA TTC ! MFIL_Taux = MFIL_Val / PC × 100 # denom = Val_Cession MLNI_Taux = MLNI_Val / CA_TTC × 100 # denom = CA TTC

4. Perequation SUIVI / NON SUIVI

AVANT LE MONTE CARLO — La perequation fournit la cible MLNI NS qui alimente le MC comme contrainte. C'est un pre-requis, pas un post-traitement.

4.1 Principe

La marge globale (MLNI total) est le mix pondere des marges SUIVI et NON SUIVI :

MLNI_total = (CA_suivi × MLNI_suivi + CA_ns × MLNI_ns) / CA_total

On inverse pour trouver le MLNI NS requis :

MLNI_NS_requis = (MLNI_cible × CA_total - MLNI_suivi × CA_suivi) / CA_ns

5.1 Parametres

5.2 Bornes de prix par produit

PVC_min (plancher marge)

PVC_min = PA / (1/coef_tva - MLNI_cible/100)

Garantit que la marge MLNI ≥ objectif

PVC_max (plafond indice)

PVC_max = Prix_Concurrent × Indice_Cible / 100

Garantit l'indice prix vs concurrent

Variation max

PVC ∈ [PVC_current × 0.85, PVC_current × 1.15]

Anti-volatilite : ±15% max

Bornes PC (cession)

PC_min = PA → MFIL ≥ 0 PC_max = CA_HT → MADH ≥ 0

Filiere et adherent ne perdent jamais

5.3 Produits en tension

Quand PVC_min (marge plancher) > PVC_max (indice plafond), le produit est en tension. Le simulateur applique une relaxation progressive :

  1. Midpoint entre les 2 bornes, ±5%
  2. Si toujours infaisable : ±3% autour du PVC actuel
  3. Dernier recours : ±1% autour du PVC actuel

6. Scoring Multi-Criteres

Score = 0.50 × S_marge + 0.35 × S_indice + 0.15 × S_lissage

6.1 Decomposition du score

Marge (50%)
MLNI 0% → 50%
Indice (35%)
Zone optimale ±2 pts
Lissage (15%)
Seuil 5% variation
ComposanteScore = 1 (optimal)Score = 0 (penalise)Parametre
S_marge MLNI_Taux ≥ 50% MLNI_Taux = 0% marge_scale_max_pct: 50
S_indice |indice - cible| ≤ 2 pts > 10 pts au-dessus, > 20 pts en dessous indice_zone_optimale_pts: 2
S_lissage Variation PVC ≤ 5% Variation PVC > 25% lissage_seuil_pct: 5

6.2 Selection du meilleur scenario

  1. Filtrer les scenarios faisables (MADH ≥ 0 ET MFIL ≥ 0)
  2. Parmi les faisables, selectionner celui avec le score max
  3. Si aucun faisable : prendre le meilleur score global (flag Is_Feasible = false)

7. Boucle de Convergence

Apres chaque run Monte Carlo, on verifie les metriques portfolio (agregees par enseigne) :

BOUCLE × 5 max
A. Perequation
Recalcul MLNI SUIVI prevu (apres MC) → derive MLNI NS requis
↓
B. Monte Carlo
10K scenarios par produit, scoring, selection du meilleur
↓
C. Verification Portfolio
Indice CA comparable = Σ(PVC_opt × Qte) / Σ(PrixConc × Qte) × 100
MLNI portfolio = Σ(CA_HT_opt - PA × Qte) / Σ(CA_TTC_opt) × 100
↓
D. Test de Convergence
CONVERGENT si |MLNI_portfolio - cible| ≤ 1 pt ET |Indice_CA - cible| ≤ 2 pts
NON CONVERGENT → retour a l'etape A avec bornes ajustees
